# TASK-001：Narraverse2.0 全系统地图

## 执行者

Workbuddy

## 任务类型

只读调查。

## 背景

现在不再只研究模块三和模块四，而要重新检查 Narraverse2.0 从资料导入到世界运行的完整链路。

当前最大疑问是：
- 总资料库、具体世界资料库之间究竟如何连接；
- 写作模式是否真正共享同一世界资料；
- 游戏模式、叙界文字冒险、自由沙盒是否其实是三套重复运行系统；
- 游戏模式已有的方案预设（故事导演、叙事风格、状态系统、TRPG 检定、事件包等）是否已经足以承载另外两种玩法。

## 目标

基于 `llys-p/Narraverse2.0` 当前真实代码和文档，做一份完整系统地图，为后续决定“渐进修改、重构核心、近乎重写”提供证据。

## 允许范围

只读整个 `llys-p/Narraverse2.0`。

可以：
- 搜索代码；
- 阅读文档；
- 追踪 API；
- 追踪前后端状态；
- 追踪数据模型；
- 追踪 iframe / postMessage；
- 追踪模型网关；
- 追踪游戏预设与 Agent。

## 禁止事项

本任务不得：
- 修改 Narraverse2.0 正式代码；
- 开始重构；
- 删除模块；
- 为了“统一”先写新框架；
- 只看 UI 就下结论。

## 必须调查的 8 个区域

### A. 资料导入与整理

找出：
- 角色卡导入；
- 设定/世界书导入；
- 翻译；
- 清洗；
- 去重；
- 字段结构化；
- 版本和来源追踪。

说明真实入口、数据落点和调用链。

### B. 总资料库

找出 Master Library / 总资料库目前真实的数据模型和 API。

说明：
- 存什么；
- 原件如何保留；
- 翻译版本如何保存；
- 角色/设定如何组织；
- 是否已有快照、来源、版本、冲突等能力。

### C. 具体世界 / 冒险资料

调查具体世界、冒险、故事档案等目前如何保存：
- 角色实例；
- 地点；
- 关系；
- 状态；
- 世界事实；
- 时间；
- 事件。

重点说明它们是否复制总库数据、引用总库数据，还是各自另建结构。

### D. 写作模式

调查写作模式到底读取什么上下文：
- 是否能读取总资料库；
- 是否能读取具体世界；
- 是否使用独立 Agent / prompt / state；
- 写作产生的事实是否会回到世界；
- 是否存在草稿/canon/非 canon 边界。

### E. 现有游戏模式

重点拆解“方案/预设”系统，必须找到真实实现：
- 故事导演；
- 叙事风格；
- 状态系统；
- TRPG 检定；
- 事件包；
- 角色状态；
- 世界状态；
- prompt 组装；
- 模型调用；
- 存档/Session。

输出它已经具备的“运行时能力清单”。

### F. 叙界文字冒险

调查它自己的：
- 状态；
- 对话/行动流程；
- 世界上下文；
- Agent；
- API；
- 模型调用；
- 存档；
- 与 Denova 的桥接。

然后和游戏模式逐项对照，标出：
- 完全重复；
- 部分重复；
- 真正独有。

### G. Module4 / 自由沙盒

调查现有流程：
- Daily Preview；
- NPC schedule；
- move/action；
- Encounter；
- Judgment；
- Facts；
- Action Logs；
- Settlement；
- 自由输入；
- 世界推进。

说明哪些能力是：
- UI；
- 运行时内核；
- 调试能力；
- 可复用业务逻辑。

并和游戏模式、文字冒险逐项对照。

### H. 技术边界

画出：
- React 前端；
- Go 后端；
- Python/8097 Bridge；
- Narraverse iframe；
- postMessage；
- 模型网关；
- Ollama/本地模型；
- 数据存储。

重点指出：
- 哪些技术差异只是正常分层；
- 哪些已经造成数据和状态割裂；
- 哪些地方存在重复 API / 重复模型配置 / 重复状态。

## 必须回答的核心问题

1. 游戏模式、叙界文字冒险、自由沙盒，是否本质上能够共享一个运行时核心？
2. 如果可以，现有游戏模式的“方案预设”能覆盖多少另外两套玩法？
3. 哪些能力应该成为统一运行时的内核？
4. 哪些只是预设开关？
5. 哪些只是不同 UI？
6. 哪些现有代码值得直接复用？
7. 哪些只能迁移数据/规则，代码本身不值得保留？
8. 哪些应该废弃？
9. 如果从零设计，现有最严重的三个结构性问题是什么？
10. 在 A 渐进整合 / B 保留资产重构核心 / C 近乎重写 三条路线中，初步更支持哪一条？这里只给初步判断，不开始实施。
